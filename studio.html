Studio Help — Scripting API & Shortcuts x

Editing

  • Click parts in the viewport or hierarchy to select. Drag the gizmo to move/rotate/scale.
  • Keys: W move, E rotate, R scale, Ctrl+D duplicate, Delete remove, Esc deselect, Ctrl+Z/Ctrl+Y undo/redo, Ctrl+S quick-save.
  • Orbit: left-drag. Pan: right-drag. Zoom: wheel.

Play-testing

Press Play in the top bar to run the place right here: WASD move, right-drag to look around, 1-9 equip tools, click or F to use the equipped tool. Press Esc or Stop to return to editing. NPC spawners (green blocks) fill the place with their NPCs while playing.

Testing scripts

Syntax is checked when you save a script or tool. Use Play above to test scripts and tools instantly — then Publish to share, or press Play on the Games page.

Script events

  • start — once when the place starts (attach to a part or global).
  • update — every frame.
  • touched — when something hits the part (player, or a moved/spawned part).
  • clicked — when the player clicks the part in game.

Global game API (all scripts)

// objects
game.parts                  // array of all parts
game.getPart('My Part')     // by name or id
game.localPlayer            // .name .health .position .teleport(x,y,z)
game.localPlayer.damage(25) // .heal(25)
game.players                // array of players

// spawn / destroy
game.spawnPart({ type: 'box', name: 'Wall', position: [0, 2, 0],
                 color: '#c04040', scale: [4, 1, 1] })
game.destroy(partOrId)

// events + timers
game.on('roundStart', fn)   // also: roundEnd, timer, touched,
                            // clicked, playerSpawn, playerDamaged
game.emit('myEvent', data)
game.startRound(30)         // emits roundStart, then timer, then roundEnd
game.after(2, fn)           // one-shot timer (seconds)
game.every(1, fn)           // repeating timer
game.cancel(timerId)

// inventory + tools
game.inventory.give('jetpack')
game.inventory.remove('jetpack')
game.inventory.has('jetpack')
game.inventory.equipped     // current tool or null
game.tools.define({ id: 'jet', name: 'Jetpack',
    onEquip() { game.toast('Equipped!') },
    onActivate() { player.teleport(player.position.x, 20, player.position.z) } })

game.toast('message')       // on-screen banner
game.text('spawn', { size: 48 }) // persistent 2D screen text (centered)
    .setText('go!')              // handle: .setText() .visible .move(x,y)
    .remove()                    // ...or remove it when you're done
game.clearTexts()           // remove every 2D text label at once
game.log('debug')           // to the console drawer

Part API (the part argument)

part.name / part.type / part.parent
part.position.x = 4          // world/local position (y up)
part.rotation.y += 0.05      // radians
part.scale.x = 2
part.color = '#ff5050'
part.setPosition(x, y, z)
part.setRotationDeg(0, 90, 0)
part.onTouch(other => ...)   // dynamic listener
part.onClick(other => ...)
part.destroy()

Tool API

Define tools in the Tools tab (equipped/activated code) or from a script with game.tools.define(...). Scripts receive (game, tool, player) in tool code. Inventory is saved into the place manifest on publish.
